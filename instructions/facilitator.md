## 1.3 Maintainer controller execution

`validate-agent-workflow.ps1` is an existing azd-based launcher. It selects one named environment and derives both Foundry and Sandbox scope from that environment:

```powershell
.\scripts\validate-agent-workflow.ps1 -EnvironmentName $authorizedEnvironmentName `
    -ManifestPath $preparedManifestPath -Mode plan -UseWsl
```

Worker mode additionally needs explicit bindings, separate validation primary and `-ApprovePlan`. `-UseWsl` passes a short-lived Foundry-only token through stdin, never a token file or command argument. It uses the existing `.venv-linux` interpreter; do not claim the Windows ARM stdlib environment can run Agent Framework. The deliberate mixed-scope retained run used the direct controller entry point instead, not this one-environment wrapper.

The participant snippets use the prepared native controller executable explicitly and Azure CLI credentials. Verify both prepared native environments before the session. Planning provisions/reuses a persistent agent and calls the model; it is not read-only. A later worker invocation creates a new run/plan under the same bounded contract rather than resuming the planning-only result. Dot-sourced command blocks preserve cross-page variables and use `Read-Host` checkpoints; later commands cannot be pasted into an interactive sign-in prompt as unparsed input. Controller progress, role/tool names and elapsed-time updates go to stderr; stdout remains the final JSON only. GPT-5.2 disables hidden reasoning in the persistent agent definition and direct worker options to preserve the lab's short output budgets. Saved-agent runs inherit that setting; sending a per-run `reasoning` override alongside an agent reference produces HTTP 400. Each run saves its exact result or `failure.json` under `.validation-workspaces\agent-runs\<run-id>`; a failed report never becomes build input. Failure records preserve available HTTP status/request IDs through SDK exception wrappers.

Governance receives the manifest's original-byte SHA-256 from the independently verified primary, separately from the dataset's logical SHA-256. Its argument-free `verify_feature` checks the same manifest bytes in its clone. The controller supplies the seven passing, run-bound primary acceptance/egress receipts and both implementation reports; governance reviews these rather than treating the absence of a separate egress tool as missing evidence. The final `worker-schema` check necessarily follows the governance report and remains mandatory. Missing, foreign or failed primary receipts, a changed manifest, and reported governance blockers still stop the run; none of these inputs authorizes release.

Each worker's response schema constrains role, run, Sandbox, dataset version and logical hash to their assigned values. This prevents transcription of a manifest-file hash into the logical-hash field. The independent identity checks and bounded report-only repair remain in place; no report is silently relabeled or accepted after a mismatch.

Worker reports put non-blocking notes and expected later-stage caveats in `summary`. `blockers` must be `[]` when no actual unresolved defect remains; a sentence such as "no blockers found" is not an empty list. The structured response schema and shared worker instructions state this explicitly. The controller never filters or discards a non-empty blocker entry, even if it is worded as a reassurance.

Controller JSON artifacts use UTF-8 with explicit LF line endings on every host. The participant comparison normalizes only CRLF to LF so older Windows results can be checked against captured stdout without rewriting them. `$resultSha256` still hashes the original file bytes, not the normalized comparison text, and is cleared before a new worker run.

The candidate image validates the frozen artifact in its runtime stage before the separate application-test stage. Keep `src/workers/frozen_contract.py` in that runtime stage: the public-data validator imports it. A failure before application testing does not establish that the eight public-data tests ran.
