# 18. Your lab notes

Use these prompts to review what you did, on your own or in a short discussion. Record only what you completed. Label any supplied example **recorded** and any fallback image **ready-made reference**.

| Activity | Keep | Question |
|---|---|---|
| Explore the application | Application URL and starter image | Which two features were missing? |
| Review the plan | The three specialist assignments | What can each specialist change? |
| Prepare the workspaces | Primary, snapshot, and worker IDs | How do the clones share a starting point? |
| Try the egress policy | HTTP status for each of the two hosts | What enforced the restriction, and why is a timeout not proof of denial? |
| Run the team | Run ID and saved result | Which checks ran independently of the workers? |
| Build and deploy | Image descriptor, ACR run, digest, target, and your deployment decision | Does the active image match what you authorized? |

The scripts retain the detailed checksums in their receipts. Keep those files with your notes; you do not need to copy long hashes into this worksheet.
