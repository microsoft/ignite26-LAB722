# Lab instructions

Follow [LAB722: Operate secure, multi-tenant agentic apps on Azure Container Apps](reactor-2-skillable.md).

This is the current guided and self-paced lab: operate the Caldova research application, inspect its Foundry-hosted orchestrator and Toolbox, observe specialist agents in on-demand Sandboxes, and verify ownership, quality checks and cleanup.

Use your assigned Skillable VM and Azure allocation. The initial desktop shortcut uses preinstalled Python dependencies; authenticate with the allocated Azure account and Temporary Access Pass (TAP). Do not use a previous allocation's resource identifiers.

For deployment from your own workstation, use the [repository quickstart](../README.md#local-deployment-quickstart) and [deployment details](../README.md#deployment-details), not the Skillable-specific preparation commands.
