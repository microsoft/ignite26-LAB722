# Self-guided media

The self-guided lab will include:

- Seven short segment videos
- One combined cut
- English WebVTT captions
- Plain-text transcripts
- Thumbnails and recording scripts

Videos will use slides and captures from the tested product. Final videos will be hosted in Microsoft Stream or its SharePoint-backed event location. The repository will keep the scripts, captions, transcripts, versioned URLs, and checksums.
